## Things a fresh session will get wrong without being told

- **The provider is Gemini, not Claude.** Swapped 2026-08-08 at Kofi's request. Nothing in Core
  names a vendor now: `IModelJsonCompletion`, `ModelSiteGenerator`, `ModelSectionAssistant`, and
  one implementation (`GeminiJsonCompletion`) in the web project. The Anthropic client and its
  package are gone — `git revert` if that is ever reversed.
- **The test suite used to spend money** — 45 onboarding call sites, each a live Opus 4.8 request.
  Fixed at the test host; no `ANTHROPIC_API_KEY=""` workaround needed now. Don't undo the blanking
  in `TenantAppFactory`, and **add any new provider's key name to that list** — the whole point is
  that a key in user secrets can never reach the test host. `TestHostGenerationTests` guards it.
- **The Jira board drifts.** Epic status is frequently wrong; derive it from children. WB-2 currently
  shows In Progress with zero open children, and WB-28 shows To Do although all four of its
  acceptance criteria are now implemented. Nothing has been transitioned — the board is shared with
  Bismark and Kofi has not said go.
- **Sign-in email locally goes to the console, by design.** There is no SMTP host in development, so
  `LogEmailSender` writes the magic link to the app log. Kofi hit this and thought Resend was broken.
  Startup now logs which mode is active.
- **A full `searchJiraIssuesUsingJql` over project WB blows the tool output limit.** Let it spill to
  the tool-results file and parse with **python** — `jq` is not installed on this machine.
- **`ui.pen` is encrypted.** It cannot be read or edited with normal file tools, only through the
  Pencil MCP with the file open in the editor — which only Kofi can do. It still says "Sitely" in
  nine places.
- **Railway blocks outbound SMTP below the Pro plan**, by dropping packets. Anything that needs an
  outbound port other than 443 will look like a hang, not an error. Reach for an HTTPS API first.
- **Railway variable names use `__`, not `:`.** A variable called `Gemini` does nothing; the app
  reads `Gemini__ApiKey`. This cost a deploy — the startup banner said "template only" while the
  key sat there looking correct.
- **Data protection keys are not persisted** (`/root/.aspnet/DataProtection-Keys` inside the
  container). Every deploy signs everyone out and invalidates in-flight antiforgery tokens. Not yet
  fixed; the fix is `PersistKeysToDbContext` plus a migration.
- **Local Postgres is on port 55440**, not 5432. `docker compose up -d`.
- **Run the app with** `ASPNETCORE_ENVIRONMENT=Development ASPNETCORE_URLS=http://localhost:5184
  dotnet run --project src/WebsiteBuilder.Web --no-launch-profile`. Omitting the environment variable
  skips `appsettings.Development.json` and the connection string never loads.
- **Stop the running app before rebuilding** — it locks the output DLLs and the build fails.
- **No AI-attribution trailer in commit messages.** Kofi rejected a commit solely for carrying one.
- **The local demo site is currently unpublished** (I set `Published = NULL`) so the first-publish
  dialog can be exercised. Sign in as `demo@joesplumbing.example`.

rather than failing — and Resend's docs list 465 as an option. The guard throws at startup with a
clear message. It is deliberately **not committed**: if the Railway port is currently 465, deploying
it takes the whole site down instead of only breaking mail. Kofi needs to check the value first.

## Payments — decided, and it affects an existing epic

- **WB-7 Billing is specced around Stripe Checkout and cannot be built as written** unless a

which composes an order message to the owner's number. No payment integration, no PCI surface, and
it matches how those sales already happen. Paystack can follow once there's demand.

## Infrastructure facts worth not rediscovering

- Cloudflare DNS, **every record DNS-only (grey cloud)**. Proxying breaks wildcard certificate
  issuance without Advanced Certificate Manager.
- Railway needs **two** custom domains: `csbuild.app` and `*.csbuild.app`. The wildcard needs two
  CNAMEs (itself and `_acme-challenge`) **plus a mandatory TXT** — wildcards don't verify without it.
- `.app` is HSTS-preloaded. No HTTP fallback; before a cert issues the domain is unreachable.
- Resend verifies the bare `csbuild.app`, sending from `no-reply@csbuild.app`: MX + SPF TXT on
  `send`, DKIM TXT on `resend._domainkey`. Names entered **without** the domain suffix.
- The `send` label is why `send` is a reserved subdomain — see `docs/PROJECT.md` §3.
